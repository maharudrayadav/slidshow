03. Core Booking Logic: Day Tour vs. Multi-Day Tour

How the frontend form and backend Spring Boot API handle dates, duration, and price calculation.

TOUR_TYPE = DAY durationDays = 1

Day Tour Flow

  • • Date Rule: User selects 1 date (startDate). System sets endDate = startDate.
  • • Duration Label: Displayed in hours (e.g., 10 Hours • Private Tour).
  • • Price Formula: totalPrice = pricePerPerson × members.
  • • Example: Cliffs of Moher (€120) × 2 guests = €240.
TOUR_TYPE = MULTI_DAY durationDays >= 2

Multi-Day Tour Flow

  • • Date Rule: User picks startDate. System auto-calculates endDate = startDate + (durationDays - 1).
  • • Duration Label: Displayed in Days/Nights (e.g., 3 Days / 2 Nights).
  • • Price Formula: totalPrice = packagePricePerPerson × members.
  • • Example: Ring of Kerry 3-Day (€650) × 2 guests = €1,300.
